# Norilight docs

Help pages for [Norilight](https://github.com/Nori-Oppi/Norilight), the streaming client,
and [Norishine](https://github.com/Nori-Oppi/Norishine), the host. Norilight's help buttons
open these pages.

| Page | When |
| --- | --- |
| [Setup guide](setup-guide.md) | Setting up a host and a client for the first time, or the PC doesn't show up |
| [Troubleshooting](troubleshooting.md) | A stream doesn't start, stutters, or looks or sounds wrong |
| [Fixing hardware decoding problems](hardware-decoding.md) | Norilight says no hardware video decoder works |
| [Gamepad mapping](gamepad-mapping.md) | Norilight says a gamepad has no mapping, or its buttons are wrong |

Each project's own guide covers its features in detail:
[Norilight's GUIDE.md](https://github.com/Nori-Oppi/Norilight/blob/main/docs/GUIDE.md) and
[Norishine's GUIDE.md](https://github.com/Nori-Oppi/Norishine/blob/master/docs/GUIDE.md).

Norilight is based on [Moonlight](https://moonlight-stream.org) and Norishine on
[Apollo](https://github.com/ClassicOldSong/Apollo) and
[Sunshine](https://github.com/LizardByte/Sunshine). These pages are written for them, and
draw on the [Moonlight documentation](https://github.com/moonlight-stream/moonlight-docs/wiki),
which also covers the other Moonlight clients and hosts.
